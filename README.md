# 짹짹이의 정선도서관 대모험

첨부 이미지와 새로 만든 동굴·대왕박쥐 이미지를 활용한 설치 없는 6스테이지 웹게임입니다.

## 실행 방법

1. `index.html`을 Chrome 또는 Edge로 엽니다.
2. 이미지 로딩이 끝나면 `모험 시작!`을 누릅니다.
3. 방향키 또는 `WASD`로 이동하고 `Space`로 순간 날갯짓을 사용합니다. 대왕박쥐 전투에서는 날갯짓 상태로 보스에게 돌진해 공격합니다.

인터넷 연결과 별도 패키지 설치는 필요하지 않습니다.

로컬 서버로 실행하려면 Node.js가 설치된 환경에서 프로젝트 폴더를 연 뒤 `node serve.mjs`를 실행하고 `http://127.0.0.1:4173`에 접속합니다. 일반 플레이에는 이 과정이 필요하지 않습니다.

## 게임 순서

1. 곰의 추격 따돌리기
2. 등산객이 던지는 돌 피하기
3. 대왕가재의 집게와 물결 피하기
4. 달려드는 개미 떼 피하기
5. 수정 동굴에서 대왕박쥐와 싸우기
6. 정선도서관 입구 도착하기

## 주요 파일

- `index.html`: 게임 화면과 접근성 구조
- `styles.css`: 반응형 UI와 모바일 조작 화면
- `game.js`: 이동, 충돌, 6개 스테이지, 효과음·배경음악, 상태 전환
- `GAME_DESIGN.md`: 전체 게임 설계
- `assets/`: 첨부 배경·캐릭터 이미지와 배경음악

## 게임 규칙

- 스테이지마다 깃털 3개로 시작합니다.
- 위험에 닿으면 깃털이 1개 줄고 잠시 무적이 됩니다.
- 깃털이 모두 사라지면 해당 스테이지부터 재도전할 수 있습니다.
- 도서관 앞의 5개 스테이지를 통과하면 책갈피를 하나씩 받습니다.

## 이미지 참고

`sparrow-hero.png`는 첨부된 원본이며, `sparrow-hero-transparent.png`는 플레이 화면용 투명 배경 버전입니다. 기존 배경은 첨부 원본을 이름만 정리해 복사했고, `05-cave-arena.png`와 `giant-bat-transparent.png`는 새 보스전을 위해 생성한 이미지입니다. 마지막 도착 장면은 첨부된 실제 정선교육도서관 사진인 `06-jeongseon-education-library.png`를 사용합니다.

배경음악은 첨부된 `Small_Wings_Broad_Sky.mp3`를 `assets/small-wings-broad-sky.mp3`로 복사해 사용하며, 모험 시작 후 반복 재생됩니다. 화면 위의 스피커 버튼으로 효과음과 함께 켜고 끌 수 있습니다.
